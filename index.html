Technical & Research Experience

Formula 1 Sustainability Analysis Website
Website

This project explores the environmental impact of Formula 1 racing and visualizes key sustainability metrics such as carbon emissions, fuel usage, race travel distances, and future projections for electric alternatives like Formula E. Built with data storytelling tools like Observable and Tableau, the interactive site transforms raw data into digestible visual insights. The project highlights how racing logistics contributes to F1's carbon footprint.

Bitcoin Fear & Greed Index
Project, Github

This project focuses on analyzing Bitcoin market sentiment using data science techniques such as natural language processing (NLP), time-series analysis, and data visualization. It aggregates sentiment data from Reddit discussions, and market volatility metrics to quantify investor sentiment. Built with Python, Plotly, and automated data pipelines, the index provides real-time insights into market psychology for traders and analysts.
